**NovaPilot** is a lightweight terminal AI personal super intelligence engine designed to provide developers with a zero-dependency, privacy-first AI interaction experience. Inspired by trending personal AI super intelligence projects on GitHub (like OpenHuman), NovaPilot introduces differentiated innovations:

- 🔒 **True Zero Dependencies**: Built entirely on Python standard library, no third-party packages needed

- 📊 **TUI Dashboard**: Beautiful curses-based terminal interface with streaming output
- 💾 **Privacy First**: All data stored locally, no cloud service dependency

## 🚀 快速开始

### 环境要求

- **Python 3.8+** （无需安装任何第三方依赖）

### 安装

```bash
# 克隆仓库
git clone https://github.com/gitstq/NovaPilot.git
cd NovaPilot

# 安装（零依赖，仅注册命令行入口）
pip install -e .

# 或者直接运行，无需安装
python3 -m novapilot.cli --help
```

### 配置 LLM 后端

```bash
# 查看已配置的后端
novapilot config list

# 添加 OpenAI 后端
novapilot config add openai --api-key sk-your-key --model gpt-4o

# 添加 Anthropic Claude 后端
novapilot config add anthropic --api-key sk-ant-your-key --model claude-3-5-sonnet-20241022

# 添加 Ollama 本地后端（需先安装 Ollama）
novapilot config add ollama --model llama3

# 测试后端连接
novapilot config test openai

# 设置默认后端
novapilot config default openai
```

### 启动对话

```bash
# 启动交互式对话
novapilot chat

# 使用指定后端
novapilot chat --backend anthropic

# 启用详细输出
novapilot chat --verbose
```

### 其他命令

```bash
# 记忆管理
novapilot memory list                    # 查看所有记忆
novapilot memory search "关键词"          # 搜索记忆
novapilot memory export --format json    # 导出记忆

# 工具管理
novapilot tools list                     # 查看可用工具
novapilot tools enable code_analyzer     # 启用工具
novapilot tools disable web_search       # 禁用工具

# 启动 TUI 仪表盘
novapilot dashboard
```

## 📖 详细使用指南

### 智能路由策略

NovaPilot 的智能路由器会根据任务类型自动选择最优的 LLM 后端：

| 任务类型 | 路由策略 | 说明 |
|----------|----------|------|
| 简单问答 | 轻量模型 | 优先使用快速、低成本模型 |
| 代码生成 | 强模型 | 选择代码能力强的模型 |
| 长文档分析 | 大上下文模型 | 自动选择支持长上下文的模型 |
| 本地优先 | Ollama | 优先使用本地部署的模型 |

### 记忆系统

NovaPilot 内置了基于 TF-IDF 的语义记忆系统：

```python
from novapilot.memory.engine import MemoryEngine

# 初始化记忆引擎
engine = MemoryEngine()

# 存储记忆
engine.remember("Python最佳实践", "使用类型注解、编写文档字符串、遵循PEP8规范", "knowledge")

# 语义搜索
results = engine.search("代码规范")
for r in results:
    print(f"[{r['category']}] {r['content']}")

# 查看统计
stats = engine.get_stats()
print(f"总记忆数: {stats['total_entries']}")
```

### 代码分析工具

```python
from novapilot.tools.code_analyzer import CodeAnalyzer

analyzer = CodeAnalyzer()

# 分析代码字符串
result = analyzer.analyze_string("""
def fibonacci(n):
    if n <= 1:
        return n
    return fibonacci(n-1) + fibonacci(n-2)
""")

print(f"函数数: {result['functions']}")
print(f"圈复杂度: {result['complexity']}")
print(f"风险等级: {result['risk_level']}")
```

## 💡 Design Philosophy & Roadmap

### Design Philosophy

NovaPilot's core design principle is **"Lightweight but Not Simplistic"**:

1. **Zero Dependency Philosophy**: No third-party dependencies, lowering installation barriers and avoiding version conflicts
2. **Modular Architecture**: Each functional module is independently pluggable for easy extension and maintenance
3. **Privacy First**: All data stored locally, no cloud service dependency
4. **Progressive Complexity**: Simple scenarios work out of the box, complex scenarios are flexibly configurable

### Technology Choices

| Component | Technology | Reason |
|-----------|-----------|--------|
| HTTP Requests | `urllib` | Standard library, zero dependencies |
| Terminal UI | `curses` | Standard library, cross-platform terminal support |
| Config Storage | `json` | Standard library, human-readable |
| Semantic Search | TF-IDF (custom) | No NLP libraries needed, lightweight and efficient |
| CLI Framework | `argparse` | Standard library, full-featured |

### Roadmap

- [ ] 🔌 **Plugin System**: Support custom tool plugins
- [ ] 🔄 **Enhanced Streaming**: Support interrupt, retry, branch conversations
- [ ] 📊 **Usage Analytics Dashboard**: Token consumption, request frequency, cost analysis
- [ ] 🌍 **More Languages**: Japanese, Korean, Spanish documentation
- [ ] 🐳 **Docker Deployment**: One-click containerized deployment
- [ ] 📱 **API Server Mode**: REST API interface
